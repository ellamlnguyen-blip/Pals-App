## Delivered boundary

- Additive `20260923000700_local_safety_reports.sql` adds private RLS report and caller-scoped retry tables with explicit client revokes and no platform-role reader. `submit_safety_report` accepts only original user, Hangout or retained Hangout-host inputs; it derives the reporter from `auth.uid()` and returns exactly an opaque UUID receipt and server timestamp. The host route stores a user report and only its caller-owned Hangout UUID as provenance reference. Peer provenance resolves to a minimal authoritative source kind/reference (owned block, friendship, immutable friend-request generation, DM generation, host Hangout or overlap Hangout), never copied source text, photo, location, roster or message.
- Category uses JavaScript-style edge trim plus lowercase; narrative uses the same edge trim, with null and empty normalized to null. `other` requires 1–2,000 characters; the remaining four categories permit empty narrative. The original mode/reference plus normalized content are fingerprinted before target resolution. Exact caller/key replay rechecks the safety gate and active account and returns the original receipt/time without any source lookup, including after source deletion. Mismatch, unknown, denied and throttled submissions use the same neutral `42501` report-unavailable error after typed REST argument parsing.
- Every submission takes A's READ COMMITTED shared mutation lock first. New reports choose retained or current path before lower locks; retained authority is freshly rechecked after safety/account locks. Current People uses A's pair and live-evidence helper; current Hangout locks parent, source gate and live caller evidence before a fresh final read check. The clock is sampled after contention. At most five **new** reports per caller in the inclusive `[now - 1 hour, now]` interval insert a report and retry row atomically. Exact replay uses no rate slot. A report changes no block, attendance, notification or sanction.
- Engineering authorization, data model, safety and testing documentation describes this local boundary. Tests are grouped by grants, source authority, replay and contention. No shared queue/state/changelog file changed.
