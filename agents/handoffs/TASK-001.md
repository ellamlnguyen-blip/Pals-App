## Decisions
- Minimal pnpm workspace scripts, no Turborepo/build service. Node 24 and pnpm 11.19.0 pinned for consistency.
- Next.js 16.3.5, React 19.3.0 and package availability checked against npm; dependency installation and builds verify compatibility. TypeScript 5.9.3 is a conservative compiler baseline.
- ESLint 9.39.1 is pinned despite its registry deprecation notice because the current Next.js React lint plugin excludes ESLint 10 in its supported peer range. Revisit with compatible upstream tooling.
- pnpm 11 `allowBuilds` explicitly permits only sharp/unrs-resolver. The legacy `onlyBuiltDependencies` setting was replaced after install surfaced its incompatibility.
- Native CSS and provisional tokens fit a static bootstrap. No marketing assets or UI library added. Taste dials: variance 3, motion 1, density 3.
- `agentRules: false` prevents Next.js dev from auto-generating nested agent control files; the repository's authored AGENTS.md remains authoritative. Generated next-env files are ignored and regenerated by `next typegen`/dev/build.
