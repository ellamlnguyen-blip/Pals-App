Read-only source audit of /private/tmp/pals-task034-ui and parent TASK-034. Read AGENTS and relevant accepted architecture, authorization, messaging, data model, privacy/safety, rich profile/People and ADR-0042. Draft concrete Proposed ADR-0043 at /private/tmp/pals-task034-adr.md plus bounded backend stage contracts at /private/tmp/pals-task034-backend-contracts.md. Do not implement schema/code or edit shared records. No runtime/DB/gates/git/hosted action.

Propose owner-private persisted conversation read watermark and last-open/use time under current source access; unread means visible incoming message after successfully displayed watermark, self messages excluded. Opening inbox or a notification must not mark chat read. Client acknowledgment only after messages actually load in visible authorized thread and only through highest displayed sequence; never clear future unseen messages, never go backwards, caller forged sequence/source denied. Initial migration semantics for existing messages explicit (recommended historical messages read at migration to avoid huge new badges; new later messages unread). Last use cannot be arbitrary supplied time; server-authoritative. No read receipt shown to others.

Propose global current-authorized conversation ordering by max(last currently visible message, owner's valid last use), fallback source time; correct keyset pagination across DM/Hangout and current blocks/consent/membership/gates; no metadata leakage from denied messages or stale owner records. Pending requests preserve existing management but exact readable-message rules apply. Preserve same-generation/new-generation and leave/rejoin semantics explicitly. Owner metadata never restores revoked source or claims latest hidden activity.

Similarity ranking must use only existing saved optional interests/year/hometown/major and currently opted-in same-campus eligible profiles. Explain deterministic score, missing-field neutral treatment, normalized exact match and shared interest weighting; no external ML/provider, no inferred location. Filters only major/year before ranking; bounded stable cursor and explicit owner-profile/ranking revision behavior so edits reset stale cursors. Do not return raw score or other private unmatched attributes just for ranking. Existing accessible profile data remains authoritative. Heart/outgoing pending indicators are owner-relative only.

Identify exact additive migration APIs/test matrix and safe disjoint file ownership for separately reviewed attention backend and ranking backend. Consider privacy/authorization source races, upgrade/idempotency, filter pagination >24 and no namesearch. Major policy needs explicit user ADR acceptance after proposal review; do not claim accepted.
