# Roadmap

## Phase 0 — Foundation
Monorepo bootstrap; environments; Supabase migrations/RLS; Vercel; Mapbox shell.

## Phase 1 — Identity + Profiles
UNC verification, onboarding, profile editing/photos/personality, block/report primitives.

## Phase 2 — Hangouts Core
Map, create/detail/join/leave, host/co-host, visibility/eligibility, location privacy, calendar.

## Phase 3 — Social + Messaging
People, friends, friend-aware ranking, hangout chat, DM requests, direct chat, notification inbox.

## Phase 4 — Safety + Measurement
Admin moderation, reports, suspension/ban, attendance confirmation, analytics, basic large-hangout safeguards.

## Phase 5 — Public UNC Launch
Seed real hangouts, staging rehearsal, domain cutover, monitor density/reliability/safety.

## Later
Expo mobile, organization accounts, polls, capacity/waitlists if proven necessary, multi-campus expansion.
