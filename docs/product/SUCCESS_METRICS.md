# Success Metrics

## Primary Outcomes
- confirmed attended hangouts/week
- unique confirmed attendees/week
- repeat attendees within 30 days
- repeat hosts within 30 days

## Supply
hangouts created/active user; % with ≥1 join; median joins; map coverage by place/time.

## Discovery
pin view→detail; detail→join; calendar→detail; friend-context→join.

## Social Loop
friend requests after shared hangouts; accepted friendships from co-attendance; future hangouts with new friends.

## Reliability/Safety
join→attendance confirmation; host cancellation; participant cancellation; reports/100 hangouts; blocks/100 active users; moderation response time.

Do not optimize raw screen time, session duration, or notification volume.
