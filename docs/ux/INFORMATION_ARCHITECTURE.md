# Information Architecture

## Primary Navigation
1. Hangouts
2. Calendar
3. People
4. Chats
5. Notifications

Header avatar opens the owner Profile directly. Safety, Analytics, Attendance, Account and Sign out sit at the bottom of the owner Profile. Account is a separate page for real name, sign-in email and password; peer profiles contain no owner utilities. See TASK-030 for local candidate and release status.

## Hangouts
Default = interactive map. Pan/zoom, locate, filter, pin→preview/detail→join. Persistent **+ Create Hangout** action.

## Calendar
Answers “what is happening when?” Day, Monday-first Week (default), and Month use campus time with previous/Today/next navigation. Independent Hosting (yellow), Attending (green) and All hangouts (blue other available campus plans) checkboxes select the visible categories. Hover/focus/tap previews show authorized public details and View Hangout; eligible blue plans may Join. Creation starts from Hangouts. Narrow Week/Month grids scroll within their own regions. Friend-attendance context remains outside the current release scope.

## People
Recommendations + search/filter + profiles + DM request + friend request. Avoid swipe/dating mechanics.

## Chats
Hangout chats + DMs/message requests.

## Notifications
Friend/message requests, messages, hangout changes/cancellation/reminders, safety/moderation.
