# UX Principles
1. Map should feel alive immediately.
2. Creating a hangout should take seconds.
3. Do not force details that can be decided in chat.
4. Friend context lowers uncertainty without popularity metrics.
5. Eligibility/privacy settings must be plain-language.
6. Avoid swipe-style people discovery.
7. Gate exact private locations appropriately.
8. Host tools should not make casual plans feel formal.
9. Calendar is social discovery/coordination, not a general calendar replacement.
10. Visibility state must always be clear.
