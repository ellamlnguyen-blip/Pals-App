# Glossary
**Hangout:** user-created real-world plan; preferred user-facing term.
**Host:** creator of one hangout.
**Co-host:** hangout-scoped helper promoted by host.
**Admin/Moderator:** platform-scoped moderation operator.
**Friend:** mutually accepted relationship used for trust/invitations/ranking; not public status.
**Campus/Friends/Invite-only:** visibility modes.
**Public location:** map/display location safe before joining.
**Private exact details:** gated meeting detail.
**Eligibility rule:** host restriction based on deliberately provided profile attributes.
